# Калькулятор калорий

Одностраничное веб-приложение для подсчёта калорий: расчёт дневной нормы и дневник питания. Без зависимостей и сборки — чистые HTML, CSS и JavaScript (ES-модули).

## Возможности

- **Дневная норма** — расчёт по формуле Миффлина — Сан Жеора с учётом пола, возраста, роста, веса, уровня активности и цели (похудение / поддержание / набор массы). Показывает базовый метаболизм, суточный расход, целевую калорийность и раскладку БЖУ.
- **Дневник питания** — встроенная база продуктов (ккал и БЖУ на 100 г), добавление порций в граммах, итоги за день и прогресс относительно целевой нормы.
- Данные (цель и записи дневника) сохраняются в `localStorage` браузера.

## Запуск

Откройте `index.html` в браузере. Из-за ES-модулей страницу нужно отдавать по HTTP, например:

```bash
npx serve .
# или
python3 -m http.server 8000
```

и открыть <http://localhost:8000>.

## Тесты

Логика расчётов (`js/calories.js`) покрыта тестами на встроенном раннере Node.js (нужен Node 18+):

```bash
npm test
```

## Структура

```
index.html            — разметка страницы
css/style.css         — стили
js/calories.js        — логика расчётов (BMR, TDEE, БЖУ, итоги дневника)
js/products.js        — база продуктов
js/app.js             — связка логики с интерфейсом
tests/calories.test.js — тесты логики
```

Значения ориентировочные и не заменяют консультацию врача или диетолога.
